# Reem Sayed Mohammed Portfolio

A responsive, static portfolio website for Reem Sayed Mohammed, Marketing Manager.

## Run locally

In VS Code, install the **Live Server** extension if needed, then right-click `index.html` and select **Open with Live Server**.

The site is buildless: it uses only `index.html`, `style.css`, and `script.js`. No package install or build step is required.

## Included checks

- Responsive layout for phone, tablet, and desktop widths
- Keyboard-accessible navigation and visible focus states
- Mobile navigation menu and functional copy-email control
- Reduced-motion fallback
